# Security policy

## Supported versions

Security fixes are made on the latest version of the project. Earlier versions are not supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue. Contact the maintainer privately through the contact method on the repository owner's GitHub profile, including a clear description, affected version, and reproduction steps where safe to share.

You can expect an acknowledgement within 14 days. Please allow time for a fix before disclosing the vulnerability publicly.

## Handling health data

This project can contain sensitive food, symptom, and health-adjacent data. Never attach real diary data, PocketBase databases, access tokens, or production configuration to an issue or pull request.
